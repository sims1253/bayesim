# Result Schema Version

Version identifier for result column contract. Increment this when
result column names or types change.

Increments on result-column contract changes (e.g., changes to the
structure of results.parquet/rds files).

## Usage

``` r
RESULT_SCHEMA_VERSION

RESULT_SCHEMA_VERSION
```

## Format

An object of class `integer` of length 1.

An object of class `integer` of length 1.

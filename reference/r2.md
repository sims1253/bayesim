# Calculate pointwise R-squared

Calculate pointwise R-squared

## Usage

``` r
r2(y, yrep, weights = NULL)
```

## Arguments

- y:

  Vector of observed values

- yrep:

  Matrix of predicted values (draws x observations)

- weights:

  PSIS weights (optional)

## Value

Pointwise R-squared values

## Examples

``` r
if (FALSE) { # \dontrun{
y <- c(1, 2, 3)
yrep <- matrix(rnorm(300), nrow = 100, ncol = 3)
r2(y, yrep)
} # }
```

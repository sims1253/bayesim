# Compute column summaries with quantiles

Compute column summaries with quantiles

## Usage

``` r
get_col_summaries(column, quantiles, name)
```

## Arguments

- column:

  A numeric vector to summarize

- quantiles:

  Numeric vector of quantile probabilities

- name:

  A string prefix for output names

## Value

A named list with quantile values, mean, and standard deviation

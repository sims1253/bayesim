# Resolve retention options for a task result

Resolve retention options for a task result

## Usage

``` r
retention_for_task_result(retain_spec, status, warnings = character())
```

## Arguments

- retain_spec:

  Canonical retention spec list with success/warning/error entries

- status:

  Task status

- warnings:

  Character vector of warnings for the task

## Value

Character vector of retention options for that task outcome

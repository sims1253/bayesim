# Create task ID from indices

Create task ID from indices

## Usage

``` r
make_task_id(data_idx, fit_idx, rep_idx, widths = NULL)
```

## Arguments

- data_idx:

  Integer. Data index.

- fit_idx:

  Integer. Fit index.

- rep_idx:

  Integer. Replication index.

- widths:

  Optional list with data, fit, rep widths. Auto-computed if NULL.

## Value

Character string task ID.

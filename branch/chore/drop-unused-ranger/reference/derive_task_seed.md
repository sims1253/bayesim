# Derive a scalar seed from an RNG state vector.

Extracts a scalar integer seed from the second element of the
L'Ecuyer-CMRG RNG state. Element 2 varies well across parallel streams
generated by nextRNGStream(), making it a good source of per-task seed
diversity.

## Usage

``` r
derive_task_seed(rng_seed)
```

## Arguments

- rng_seed:

  Integer vector from create_task_rng_streams()

## Value

Positive integer seed
